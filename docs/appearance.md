# 外观设置与方案 1 深化

用户已选择方案 1（Power Path）。浅色沿用 concept-01.png，深色以 concept-01-dark.png 为参考。布局、信息顺序和电力流向保持一致。

## 外观交互

- 设置 → 外观，提供“跟随系统”“浅色”“深色”三个互斥选项，默认跟随系统。
- 跟随系统：读取当前有效外观，并监听系统变化；系统自动外观切换时无需重启应用。
- 手动浅色/深色：忽略后续系统外观变更，直到用户切回跟随系统。
- 切换立即生效，自动保存偏好；保留当前页面、趋势时段、曲线选择和输入焦点。
- 同一外观覆盖实时、趋势、健康、设置、指标说明、提示和滚动条；桌面/系统菜单栏仍遵循操作系统，不由本应用改色。
- 原生实现应保存枚举 `system | light | dark`，而不是保存当前解析出的颜色。跟随系统不是第三套配色。
- 原型以浏览器 `prefers-color-scheme` 表示系统外观，使用浏览器本地存储保存偏好；不改变用户 macOS 设置。评审控制区提供“模拟系统外观”，只用于测试。
- 无法读取保存值、保存内容损坏或存储被禁用时回退跟随系统；本次会话仍允许切换，并提示设置未能保存。

## 冻结的语义颜色

| 语义 | 浅色 | 深色 |
|---|---|---|
| 主表面 | #F3F6FA | #252D38 |
| 主文字 | #202632 | #F2F5FA |
| 次文字 | #606C7E | #B5BFCC |
| 分隔线 | #D4DCE7 | #414B59 |
| 输入/操作 | #316BCF | #83ACFF |
| 充电/正常 | #147E76 | #77D4C3 |
| 持续插电放电 | #98600D | #F0BD72 |

功率含义不随主题变化；蓝色一直代表输入，青色一直代表充入电池。放电同时使用负号、箭头和文案，避免只靠颜色区分。

## 验收

1. 首次启动跟随系统；在系统浅色/深色下解析正确。
2. 手动主题在刷新后保留，系统变化不覆盖手动选择。
3. 切回跟随系统立即使用当前系统外观，之后继续响应变化。
4. 所有页面、说明层、趋势线与空状态切换一致。
5. 缺失值、输入功率、放电负号及健康信息在两种外观中可读。
6. 切换主题不改变供电场景、数据或当前页；减少动态效果时不使用主题过渡动画。
