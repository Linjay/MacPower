# MacPower v0.1.7 · 预览版

优化电源功率流向布局，让箭头与实际供电方向、对应模块保持一致。

## 更新

- 外接电源充电时，两条向下分支分别对准“整机耗电”和“充入电池”图标正上方。
- 电池供电时，向左箭头移动到电脑和电池图标之间，与两侧图标垂直居中。
- 插电补充供电时，同时展示蓝色输入分支和橙色电池放电箭头。
- 两侧模块采用等宽布局，统一线条与圆角，缩短电池供电时的上方留白。
- 保留功率正负号、来源说明、估算标签与点击入口；电池功率缺失、过期时不显示电池活动箭头。

## 下载与升级

下载 `MacPower-0.1.7-arm64.zip`，解压后先退出旧版，再将 `MacPower.app` 替换到“应用程序”。本地历史与已有设置会保留。

- 适用于 Apple Silicon Mac，最低部署目标 macOS 14；本轮实机环境为 macOS 27.0.1、arm64。
- `SHA256SUMS` 用于核对 ZIP，`verification.json` 记录源码提交、构建及验证范围。

## 验证与边界

- 52 项自动测试通过，Release 构建、严格签名完整性与 ZIP 校验通过。
- 使用实际 SwiftUI 流向视图生成 48 张状态、主题及宽度组合的模拟渲染，检查充电与电池供电对照，以及补充供电、缺失和过期读数的代表场景。
- 同功能的本机修复版（包版本 0.1.6 / 7）已实际确认深色充电场景的箭头对齐、实时读数及来源说明入口；电池供电等其他状态和浅色效果来自模拟渲染，不作为真实硬件状态验证。
- 预览包使用临时签名，尚未完成 Developer ID 签名或 Apple 公证，下载后可能被 Gatekeeper 拦截。
- 本轮未扩展其他设备、旧版系统、下载后安装启动、长期性能或功率校准验收。
