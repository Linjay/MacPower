# MacPower v0.1.2 · 预览版

新增版本检查与下载入口，并包含自 v0.1.1 以来的紧凑菜单栏和能源模式显示改进。

## 更新

- 在“设置 → 软件更新”、应用菜单、菜单栏右键菜单和关于页检查新版本；显示发行说明并提供适合当前架构的下载入口。
- 可选择每天自动检查（默认关闭）和包含预览版（默认开启）。使用公开 GitHub 发布信息，不发送功率历史、硬件标识或用户凭证。
- 正确比较版本数字及预发布标识，跳过草稿，避免降级提示；区分没有可用版本、断网、异常响应和 GitHub 限流，保留官方发布页备用入口。
- 菜单栏宽度随内容收紧，减少图标、数字和单位之间的空间。
- 放电时展示当前供电来源对应的能源模式；数字颜色和文字区分自动、节能与高性能，状态图标保持单色模板。模式只读，不修改系统配置。

## 下载与升级

下载 `MacPower-0.1.2-arm64.zip`，解压后先退出旧版，再将 `MacPower.app` 替换到“应用程序”。本地历史和已有设置保留。

- 此附件适用于 Apple Silicon Mac，最低部署目标 macOS 14；本轮实机环境为 macOS 27.0 (26A428)、arm64。
- v0.1.0 / v0.1.1 没有内置更新入口，需先从发布页下载本版。后续版本由浏览器下载，仍需手动退出、替换应用；本版不提供应用内自动安装或重启升级。
- `SHA256SUMS` 用于核对下载文件；`verification.json` 记录源码提交、构建摘要及验证范围，不附带个人历史或硬件标识。

## 验证与边界

- 46 项自动测试通过，包含 17 项新增更新测试；Release 构建、临时签名完整性和 ZIP 校验通过。
- 原生更新页、菜单跳转、真实 GitHub 限流提示及浏览器发布页入口已验证；新版本识别、下载包选择和每日调度主要由模拟响应与夹具覆盖，不等于真实升级安装验收。
- 本轮未扩展功率准确性、旧系统/Intel 兼容、24 小时后台运行或完整无障碍验收。
- 应用仍使用临时签名，尚未进行 Developer ID 签名及 Apple 公证，下载后可能被 Gatekeeper 拦截。按 [Apple 的说明](https://support.apple.com/102445) 处理单应用授权，或从源码执行 `zsh scripts/test.sh` 与 `zsh scripts/build-app.sh` 构建。

完整记录见 [原生验收报告](https://github.com/Linjay/MacPower/blob/v0.1.2/docs/native-acceptance.md)。
