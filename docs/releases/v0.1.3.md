# MacPower v0.1.3 · 预览版

菜单栏电池图标与数字随当前 macOS 能源模式同步变色，方便直接辨认正在使用的能源策略。

## 更新

- 节能显示绿色，自动显示蓝色，高性能显示橙色；电池图标保留当前电量与充电形状。
- 电池供电读取电池模式，插电读取外接电源模式，包括充电、满电、闲置与电池补充供电。
- 模式未知或数据过期时恢复系统单色模板图标与默认文字色，不推定为自动模式。
- 颜色按菜单栏自身外观解析，保留紧凑布局、悬停模式来源及无障碍文字；只读系统设置。

## 下载与升级

下载 `MacPower-0.1.3-arm64.zip`，解压后先退出旧版，再将 `MacPower.app` 替换到“应用程序”。沿用本地历史与已有设置。

- 附件适用于 Apple Silicon Mac，最低部署目标 macOS 14；本轮实机环境为 macOS 27.0.1、arm64。
- 通过浏览器下载并手动替换应用；不提供应用内自动安装或重启升级。
- `SHA256SUMS` 用于核对下载文件，`verification.json` 记录源码提交、构建摘要及验证范围，不包含个人历史或硬件标识。
