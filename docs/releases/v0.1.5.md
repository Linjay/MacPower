# MacPower v0.1.5 · 预览版

降低趋势图、隐藏窗口与菜单栏的重复刷新开销，保留实时读数、后台记录与完整数据导出。

## 更新

- 分钟级趋势使用独立显示快照，最多每 15 秒更新；固定快照时间轴，未变化的图表跳过重建，缓存 15 分钟、1 小时与 24 小时查询。
- 可见的功率页面仍每秒更新实时读数；最小化或完全遮挡后恢复后台采样频率，隐藏页面停止接收常规实时刷新，再显示时立即同步。
- 设置页不提高采样频率，重复的可见性通知不再重启定时器。
- 菜单栏图标、数字和主题仅在相应输入变化时更新；保留电量连续填充、充电闪电和能源模式颜色。
- 增加可指定 CPU 预算的进程性能检查脚本。历史记录、来源断点、能量积分与 CSV 导出继续使用完整采样数据。

## 下载与升级

下载 `MacPower-0.1.5-arm64.zip`，解压后先退出旧版，再将 `MacPower.app` 替换到“应用程序”。沿用本地历史与已有设置。

- 适用于 Apple Silicon Mac，最低部署目标 macOS 14；本轮实机环境为 macOS 27.0.1、arm64。
- `SHA256SUMS` 用于核对 ZIP，`verification.json` 记录源码提交与构建验证，不附带个人历史或硬件标识。

## 验证与边界

- 46 项自动测试通过，Release 构建、严格签名完整性及 ZIP 校验通过。
- 同机短测中，24 小时趋势平均 CPU 约 6.3% → 2.0%，最小化约 6.1% → 0.5%；前后供电模式有变化，观测窗口为 15–30 秒，不能作为严格固定条件基准或固定提升比例承诺。
- 相同功能的本机修复版已验证实时读数、趋势更新与历史继续落盘；当时包版本为 0.1.4 / 5，不将该运行时结果冒充 v0.1.5 下载后的安装验收。
- 修复版纯后台两分钟平均 CPU 为 0.53%，仍略超原定 0.5% 目标。后台 RSS 约 154 MiB，仍未达到原 80 MB RSS 目标；physical footprint 独立快照为 51.0M，两种口径分别保留。
- 此前观察到的后台 95% CPU 异常未捕获现场调用栈，具体根因仍未确认，不能宣称此版本已彻底消除该异常。其他设备、旧系统、长期耗电、泄漏及长期历史规模仍未扩展验收。
- 预览包使用临时签名，尚未完成 Developer ID 签名或 Apple 公证，下载后可能被 Gatekeeper 拦截。

完整记录见 [原生验收报告](https://github.com/Linjay/MacPower/blob/v0.1.5/docs/native-acceptance.md)。
