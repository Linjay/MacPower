# MacPower v0.1.10 · 预览版

满电状态更清楚，面板与菜单栏使用一致的内嵌勾选。

## 更新

- 系统确认已充满时，电池内部显示勾选，替代充电闪电；菜单栏保持原有紧凑尺寸和能源模式配色。
- 面板保留实际电池净功率，将“已充满”作为次级说明，移除重复的完成徽标。
- 满电时只显示电源到整机的供电连线；电量行可直接进入电量趋势。
- 未知电量保留问号或占位，缺失功率不当作零；100% 但系统未报告满电时不显示满电勾选。
- 保留 v0.1.9 的电量趋势、历史格式和 CSV 兼容性，并兼容读取本地草稿中已有的电量记录。

## 使用与验证

适用于 Apple Silicon Mac，macOS 14 或更新版本。已有用户可在“设置 → 软件更新”检查并更新，或使用 README 中的一行安装命令。

预览版使用临时签名，尚未进行 Developer ID 签名或 Apple 公证。自动测试、图标渲染与本机验证范围见 [原生验收记录](https://github.com/Linjay/MacPower/blob/v0.1.10/docs/native-acceptance.md)。
