# MacPower v0.1.0 · 预览版

首个原生 macOS 菜单栏版本，可查看电源输入、电池充放电、整机耗电和电池健康。

## 功能

- 菜单栏显示固定口径的电池净功率，也可切换输入、整机耗电或电量。
- Power Path 实时面板区分供电能力、实际输入、设备运行与电池流向。
- 浅色、深色、跟随系统三态外观，设置自动保存。
- 15 分钟 / 1 小时 / 24 小时趋势、本地分钟记录和真实 CSV 导出。
- 系统最大容量、健康状况、循环次数；缺失数据不伪造为零。
- 只读采集、无管理员辅助进程；登录启动和提醒默认关闭。

## 下载与构建

`MacPower-0.1.0-arm64.zip` 为 Apple Silicon 构建。解压后打开 `MacPower.app`；关闭窗口后程序仍在菜单栏运行。

`SHA256SUMS` 包含下载附件的 SHA-256 摘要，`verification.json` 记录源码提交与验证结果。源码可通过 `zsh scripts/test.sh`、`zsh scripts/build-app.sh` 测试和构建；可复用 `zsh scripts/package-release.sh` 打包。

代码最低部署目标为 macOS 14，实际验证为 M4 Pro / macOS 27.0；不包含 Intel 构建，不宣称旧版系统和全部机型已验证。

## 验证与已知限制

- 23 项自动测试通过，32 项有效实机字段对照通过；3 项因前后采样发生变化而无法判定。
- 原生主题切换、实时/趋势/健康页、CSV 落盘、历史暂停恢复已验证。
- 10 分钟后台平均 CPU 0.36%；最终收尾包短时回归平均 CPU 0.30%，记录持续落盘。RSS 约 154 MiB，未达到原定 80 MB 目标；physical footprint 快照约 61 MiB，不能与 RSS 混为同一指标。
- 睡眠唤醒、旧版系统/其他机型、系统通知及登录启动授权、完整无障碍与长期历史规模测试仍待补齐。
- 温度与原始设计/满充容量尚未验证，界面保留为空；读数是设备端遥测或标注的估算，不等于外接功率表校准。
- 当前包仅使用临时签名，未进行 Developer ID 签名与 Apple 公证。下载包可能被 macOS Gatekeeper 拦截，因此按预览版发布，也可选择从源码自行构建。

完整记录见 [原生验收报告](https://github.com/Linjay/MacPower/blob/v0.1.0/docs/native-acceptance.md)。测试期间的原始诊断与个人运行历史不随仓库发布。
