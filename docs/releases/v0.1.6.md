# MacPower v0.1.6 · 预览版

修复点击“检查更新”时因 GitHub API 限流而无法取得版本信息的问题。

## 更新

- GitHub API 限流时，自动改用公开发布订阅、版本页与附件列表继续检查更新。
- 依据 GitHub 发布标记区分正式版和预览版，只提供发布列表中确实存在的当前架构安装包。
- 正式版检查能够找到较早的正式版，不会因近期发布均为预览版而漏报。
- 将旧版保存的 API 等待时间迁移为仅暂停 API 请求，备用来源仍可使用；等待期间避免反复请求受限 API。
- 保留网络或异常响应的错误提示、官方发布页入口、每日自动检查与已有设置，不需要 GitHub 登录或凭证。

## 下载与升级

下载 `MacPower-0.1.6-arm64.zip`，解压后先退出旧版，再将 `MacPower.app` 替换到“应用程序”。本地历史与已有设置会保留。

- 适用于 Apple Silicon Mac，最低部署目标 macOS 14；本轮实机环境为 macOS 27.0.1、arm64。
- `SHA256SUMS` 用于核对 ZIP，`verification.json` 记录源码提交、构建及验证范围。
- 更新检查只读取 GitHub 的公开发布信息，不发送功率记录、硬件标识或用户凭证。

## 验证与边界

- 52 项自动测试通过，包含 23 项版本更新测试；Release 构建、严格签名完整性与 ZIP 校验通过。
- 同功能的本机修复版（包版本 0.1.5 / 6）已实际验证公开来源能够获取版本信息，原生更新页点击检查成功。此项与 v0.1.6 安装包验证分别记录，不作为下载后安装升级验收。
- 预览包使用临时签名，尚未完成 Developer ID 签名或 Apple 公证，下载后可能被 Gatekeeper 拦截。
- 其他设备、旧版系统、24 小时自动检查调度与长期运行未扩展验收；既有性能及硬件测量边界见原生验收记录。

完整记录见 [原生验收报告](https://github.com/Linjay/MacPower/blob/v0.1.6/docs/native-acceptance.md)。
