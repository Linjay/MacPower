# MacPower v0.1.9 · 预览版

新增电池电量曲线，查看剩余电量随时间的变化。

## 更新

- “趋势”页增加“电量 / 功率”切换，电量使用独立的 0–100% 纵轴，保留原有功率曲线。
- 支持最近 15 分钟、1 小时和 24 小时；完整趋势窗口继承当前指标与时段。
- 悬停或拖动查看实际时间与电量，显示首末电量、变化百分点和记录覆盖率；睡眠、退出及读数缺失处断线。
- 本地历史和 CSV 增加电量记录，兼容已有功率历史；沿用原有采样与图表刷新频率。

## 使用与验证

适用于 Apple Silicon Mac，macOS 14 或更新版本。电量曲线需要系统提供有效的内置电池电量；旧功率记录无法回填电量，新数据在开启本地历史记录后逐步积累。

68 项自动测试通过；已生成 16 组深浅色原生界面预览，并验证主要交互。本机系统报告未安装内置电池，因此本机只验证了真实空状态，尚未验证真实充放电电量曲线。详细范围见 [原生验收记录](https://github.com/Linjay/MacPower/blob/v0.1.9/docs/native-acceptance.md)。

预览版使用临时签名，尚未进行 Developer ID 签名或 Apple 公证。已有用户可使用应用内更新或 README 中的一行安装命令升级。
