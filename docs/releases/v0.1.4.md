# MacPower v0.1.4 · 预览版

菜单栏电池图标按真实电量连续填充：满电全满、半电半满，充电时也保留实际比例。

## 更新

- 电池内部从左到右按 0–100% 连续填充，替换此前每 25% 一档的电池符号。
- 充电时在真实填充上叠加闪电，不再显示为固定满格。
- 保留节能绿色、自动蓝色、高性能橙色，以及模式未知或过期时的系统单色模板。
- 电量缺失、无效或过期显示问号；悬停与无障碍文字包含电量。提供 1×/2× 图像，保留紧凑布局。

## 下载与升级

下载 `MacPower-0.1.4-arm64.zip`，解压后先退出旧版，再将 `MacPower.app` 替换到“应用程序”。沿用本地历史与已有设置。

- 适用于 Apple Silicon Mac，最低部署目标 macOS 14；本轮实机环境为 macOS 27.0.1、arm64。
- `SHA256SUMS` 用于核对 ZIP，`verification.json` 记录源码提交与构建验证，不附带个人历史或硬件标识。

## 验证与边界

- 46 项自动测试通过；3,328 组 AppKit 离屏像素检查覆盖每个整数百分比、缺失及无效值、充电状态、四种模式、浅色/深色和 1×/2×。
- Release 构建、严格签名完整性及 ZIP 校验通过。相同功能代码已在本机安装，原生弹层显示真实充电数据；当时版本元数据仍为 0.1.3 / 4，不计作 v0.1.4 下载后安装验收。
- 未取得真实菜单栏截图；0%、50%、100% 与完整颜色/主题矩阵来自离屏夹具。其他设备、旧系统、长期运行和完整无障碍矩阵仍未扩展验收。
- 预览包使用临时签名，尚未完成 Developer ID 签名或 Apple 公证，下载后可能被 Gatekeeper 拦截。

完整记录见 [原生验收报告](https://github.com/Linjay/MacPower/blob/v0.1.4/docs/native-acceptance.md)。
