# MacPower v0.1.8 · 预览版

在应用内完成更新，免去打开浏览器、下载解压和手动替换。

## 更新

- “设置 → 软件更新”发现新版本后，点击“更新”自动下载、校验、安装并重新启动。
- 下载和校验期间旧应用继续运行，历史和设置保留；只有准备完成后才正常退出、替换应用。
- 替换或启动失败时恢复旧版；更新页显示失败原因并支持重试。
- 应用内与命令行共用安装逻辑，自动检查只提示可用版本，由用户点击后开始安装。

## 安装和使用

Apple Silicon Mac，macOS 14 或更新版本。已有旧版可使用 README 中的一行安装命令升级到本版；本版起可在应用内安装后续更新。

预览版使用临时签名，尚未进行 Developer ID 签名或 Apple 公证。系统安全授权按 macOS 的提示进行。

验证范围见 [原生验收记录](https://github.com/Linjay/MacPower/blob/v0.1.8/docs/native-acceptance.md)。
