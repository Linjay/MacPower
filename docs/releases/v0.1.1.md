# MacPower v0.1.1 · 预览版

菜单栏默认显示 **整机耗电**，方便直接查看 Mac 当前运行的总功率。充入电池的功率仍在面板中独立显示。

## 更新

- 首次启动默认使用整机耗电，缺失或过期数据继续显示 `— W`。
- 保留已保存的指标选择；从 v0.1.0 升级后，可在“设置 → 外观与显示 → 显示指标”选择“整机耗电”。
- “关于”页从应用包读取实际版本号，避免升级后显示旧版本。
- ZIP 只包含应用包文件，不附带构建机器的扩展属性或 AppleDouble 元数据。
- 同步菜单栏规则、使用说明与本机验收记录。

## 下载与验证

下载 `MacPower-0.1.1-arm64.zip`，解压后将 `MacPower.app` 放入“应用程序”。安装前先退出正在运行的旧版本；本地历史和偏好会保留。

- Apple Silicon 构建，最低部署目标 macOS 14；本次实际验证环境为 macOS 27.0 (26A428)。
- 23 项现有自动测试通过，Release 构建及应用包签名完整性检查通过。
- `SHA256SUMS` 用于核对附件，`verification.json` 记录发布提交、构建摘要和实际验证范围。
- 本次未重新测量耗电、性能、硬件精度或完整设备兼容矩阵；此前未验证的范围继续保留。

应用仍使用临时签名，未进行 Developer ID 签名或 Apple 公证。本次已将发布包解压安装至 `/Applications/MacPower.app`，文件与发布包一致，但本机 Gatekeeper 拒绝启动，尚未完成该安装路径的启动验收。需要单应用授权时请按 [Apple 的说明](https://support.apple.com/102445) 操作；也可从源码执行 `zsh scripts/test.sh` 与 `zsh scripts/build-app.sh` 构建。

完整记录见 [原生验收报告](https://github.com/Linjay/MacPower/blob/v0.1.1/docs/native-acceptance.md)。
