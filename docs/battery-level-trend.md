# 电池电量趋势交互

设计日期：2026-10-15。基于现有 Power Path 原生布局，最低 macOS 14。

## 入口与浏览

- “趋势”页增加“电量 / 功率”切换，默认电量。两个指标分别使用 % 和 W，不共用纵轴。
- 共用现有 15 分钟、1 小时、24 小时时段；切换指标保留时段与功率曲线选择。
- 实时页的电量区域增加“查看电量趋势”入口；原有迷你功率趋势仍直接进入功率视图。
- “打开完整趋势”继承指标、时段及功率曲线选择；导出当前时段 CSV 同时保留电量与原有功率列。

## 图表与读数

- 电量纵轴固定 0–100%，使用现有青色实线，线性连接真实记录，不平滑制造过冲。
- 每分钟保留末次有效电量与实际采样时间。悬停或拖动图表查看时间与电量；空白缺口不显示虚构读数。单点记录仍可见。
- 图下显示首条、末条有效电量与变化，变化单位为“百分点”。同时显示实际记录起止时间与电量记录覆盖率；跨缺口变化只是两条读数之差，不解释为连续充放电量。
- 标注“系统电源信息 · 每分钟末次读数”；不把剩余电量与健康最大容量混淆。

## 数据状态

- 睡眠、退出、关闭历史记录、无效或缺失电量形成断点；缺失从不按 0% 绘制。功率来源变化本身不使电量失效。
- 旧历史缺少电量字段时继续读取功率；电量显示“还没有电量记录”，解释从本次运行开始积累，不回推旧电量。
- 一条有效读数显示单点及“等待更多记录”；没有内置电池时说明设备范围。历史关闭时仍可浏览既有记录，并提供前往数据设置的入口。
- 沿用跟随系统、浅色、深色及文字标签；图表有无障碍描述和文字摘要。保持现有 15 秒显示快照与后台采样策略。

## 本轮范围

原生历史采集、兼容读取、交互图表、CSV 与验证；不增加充电控制、预测、通知申请或额外采集频率。
