# MacPower 交互与视觉规格 v0.1

这份规格定义完整产品流程。三张生成图用于选择视觉方向，不是逐像素实现稿，也不代表已经实现可点击原型。指标与状态以 [产品方案](product-design.md) 为准。

## 1. 视觉原则

设计目标是接近 macOS 自带的实用工具：菜单栏克制，展开后信息清楚，复杂说明按需出现。功率读数有层级，电源与电池有方向，未知状态有解释。

独特视觉元素是“电力流向”：电源、Mac、电池之间的关系随着供电状态改变。它表达真实方向，不以动画速度暗示没有校准过的精确流量。减少动态效果时完全静止，含义仍由箭头和文字给出。

不把每个指标单独装进卡片。优先用间距、对齐和细分隔线组织信息；色彩用于来源、状态与曲线，不用于装饰。

## 2. 设计变量

以下是首选基线，各方向可以调整布局和局部配色。用户选择方向后，再冻结一套明暗模式变量，不把三种方向拼成一个界面。

| 变量 | 浅色基线 | 深色基线 | 用途 |
|---|---|---|---|
| 面板 | #F5F6F8 | #262C36 | 原生材料的参考底色，透明度交给系统 |
| 主要文字 | #202632 | #F1F4F8 | 标题、主要读数 |
| 次要文字 | #687382 | #B1BBC9 | 标签、时间、解释 |
| 电源输入 | #376ACB | #B8B6F6 | 输入来源与输入曲线 |
| 电池充电 | #177E70 | #7DD6D1 | 充入电池、正常状态 |
| 需要关注 | #9B5A0A | #F0BD72 | 持续插电放电等状态 |
| 错误/系统维修建议 | 系统红 | 系统红 | 仅用于明确错误或系统状态 |

使用系统语义色优先；上述值是设计参考，落地时测试对比度，正文目标至少 4.5:1，较大文字与必要图形至少 3:1。

- 字体：SF Pro / 中文回退 PingFang SC；数值启用 monospacedDigit。无需下载字体。
- 字阶：主功率 30–32 pt、次级功率 24 pt、标题 17 pt、正文 13–14 pt、辅助说明 11–12 pt。主功率最多一位小数。
- 间距：4/8/12/16/24 pt；弹层侧边距 20–24 pt，相关行 8 pt，不同分组 20 pt。
- 图标：SF Symbols 中电池、插头、笔记本、折线图、信息、齿轮等语义图标；线宽和字号匹配。正式应用的菜单栏使用 template 单色图标。
- 圆角：弹层跟随系统；内部控件使用原生圆角，原则上不出现嵌套卡片。
- 控件：分段控件 28–30 pt 高；图标按钮可见图形 16 pt、点击区域至少 28×28 pt；菜单和设置采用平台标准键盘与焦点行为。
- 动效：面板切换约 150 ms，数值不做滚轮翻牌；流向提示只在面板打开且新数据有效时出现，不持续占用动画循环。

## 3. 菜单栏与窗口行为

| 操作 | 结果 |
|---|---|
| 左键菜单栏图标 | 打开实时页；再次点击关闭 |
| 点击弹层外 / Escape | 关闭弹层，焦点返回菜单栏入口 |
| 点击实时 / 趋势 / 健康 | 在同一弹层中切换；保持相近宽高，避免横向跳动 |
| 点击指标或信息图标 | 展开指标说明；Escape 先关闭说明，再关闭主弹层 |
| 点击齿轮 | 打开设置窗口，关闭瞬态弹层 |
| 点击“完整趋势” | 打开独立详情窗口，保留已选时段与曲线 |
| 右键或 Control-click 入口 | 原生菜单：打开面板、设置、打开系统电池设置、退出 MacPower |
| Command-comma（应用活动时） | 设置；不抢占其他应用的快捷键 |

首启直接在菜单栏运行，首次打开显示一行可关闭提示：“+ 表示充电，− 表示放电”。不遮挡实时读数。若系统隐藏菜单栏项目，使用平台允许的提示或设置入口，不承诺强制将图标移动到刘海可见区域。

默认菜单栏只显示整机耗电，电量可由用户额外开启；电池净功率仍可在设置中选择。显示值稳定宽度；屏幕空间不足时先移除可选电量，再降为图标，完整读数始终在弹层中。用户切换到其他指标后，悬停和无障碍名称随之改变。

多显示器时弹层跟随被点击的菜单栏项目；外接屏和刘海屏都不能让面板超出可见工作区。高度不足时只让内容区域滚动，页签和顶部入口保持可操作。

## 4. 实时页

推荐基准宽 416 pt，高约 620 pt；高度随辅助提示略有变化。概念稿的截图像素不作为布局尺寸契约。

| 自上而下区域 | 内容 | 交互 |
|---|---|---|
| 顶部工具区 | MacPower、设置入口 | 设置进入独立窗口 |
| 页签 | 实时 / 趋势 / 健康 | 键盘可切换 |
| 状态句 | 外接电源 · 正在充电等 | 有系统原因时可展开 |
| 功率主区 | 输入与整机、电池的数值和关系 | 点击任一指标查看定义与来源 |
| 适配器说明 | 供电能力 65 W · 系统报告 | 展开名称、报告电压/电流等可用信息 |
| 电量区 | 65%、充电/放电状态、有效时间估计 | 进入电池详情 |
| 迷你趋势 | 最近 15 分钟电池净功率 | 点击进入趋势页的同一区间 |
| 健康摘要 | 最大容量、系统状况、循环次数 | 整行可点击进入健康页 |

### 功率关系的状态变化

- 充电：输入节点分向整机与电池，电池读数 `+27.6 W`，文字“充入电池”。
- 放电：电池节点指向整机，电池读数 `−12.4 W`，文字“电池放电”；电源显示“未接入”。
- 插电且放电：电源和电池共同指向整机，电池使用负值；辅助文案“电池正在补充供电”。
- 暂停/满电：电源指向整机，电池保留静态图标；不存在继续流入电池的动画。
- 只有部分读数：保留可确认的方向，缺失节点显示 `—`；不画按比例分配的条形图。

功率未知时仍可显示系统提供的供电状态。只有状态标志、没有可靠功率时，箭头只代表供电方向，不带流量比例。

### 指标详情层

示例内容：“电源输入 / 61.6 W / 当前进入 Mac 的直流功率。与适配器报告的 65 W 供电能力不同。来源：设备遥测。更新时间：19:42:08。”

估算项显示公式和口径：“整机耗电为输入减去电池净功率的估算，可能包含转换损耗。”用户不需要看原始字段名；诊断导出才保留技术字段。

来源不可用时写“当前机型或系统未提供该数据”，读取失败时写“暂时无法读取，正在重试”，两种原因不能混用。

## 5. 趋势页

沿用 416 pt 宽度，页面结构为：时段选择、功率图、指标图例、区间摘要、供电事件、完整趋势入口。

| 元素 | 规格 |
|---|---|
| 时段 | P0：15 分钟、1 小时、24 小时；切换保留选择的曲线 |
| 图例 | 电源输入蓝色实线、整机耗电中性虚线、电池净功率青色实线；至少保留一条 |
| 横轴 | 本地时间，跨天显示日期；导出另带时区与 UTC 时间 |
| 纵轴 | W；同图单轴，电池放电区为负，零线可见；不使用误导性的双轴 |
| 指针 | 悬停显示时间、各读数、来源、是否估算；键盘左右键移动取样点 |
| 状态事件 | 插入/拔出/开始充电/暂停/唤醒，用低密度标记，聚合重叠事件 |
| 区间摘要 | 平均功率、峰值、已记录时长；Wh 放到详情，需标覆盖率 |
| 曲线断点 | 缺失、睡眠、来源变化不连线；断点可查看原因 |

独立详情窗推荐 800×600 pt、最小 680×480 pt；提供更大曲线、同一区间摘要、事件列表和“导出 CSV”。不引入第二套信息架构。没有历史时显示真实空状态和开始记录时间。

CSV 包含时间、时区、状态、各指标值、单位、来源、质量和覆盖时长。空值导出空值，不输出 0；适配器报告供电能力与实时输入分别成列。导出当前选择区间，使用系统保存面板。

## 6. 健康页

顶部以系统状态“正常”或“建议维修”作为语义结论，其次才是健康百分比。主要布局是最大容量读数和一组对齐的信息行。

| 区域 | 内容与规则 |
|---|---|
| 状况摘要 | 系统状况；最大容量 100% · 系统报告；“并非剩余电量”解释入口 |
| 当前信息 | 循环次数、电池温度、满充容量、设计容量；缺失明确说明 |
| 容量历史 | 同来源每日快照；有足够记录后显示折线，保留来源改变/更换电池分段 |
| 循环解释 | 累计使用相当于一次完整电量算一次循环，不是插电一次算一次 |
| 系统入口 | 打开 macOS 电池设置；链接失败时给出手动路径 |

温度缺失不影响其他信息；只显示一次简短说明。不要把满充容量除以当前电量，也不要用 65% 电量推算 65% 健康度。

容量估算与系统报告同时可用但不同，应并列标注来源；主结论优先系统报告，趋势也不偷偷切换来源。估算超过 100% 时保留原始值并解释，主界面不以“更健康”评价。

长期曲线没有数据：显示“从今天开始记录电池容量”，副文案“积累足够记录后可查看变化”；不预置假下降曲线。健康图不绘制“预计报废日期”。

## 7. 设置窗

推荐 640×460 pt，使用原生侧栏或分组表单，分类为“显示”“记录”“提醒”“关于”。

| 分类 | 设置 | 反馈 |
|---|---|---|
| 显示 | 菜单栏指标：电池净功率/电源输入/整机耗电/电量；额外显示电量 | 即时预览菜单栏格式，标清当前选中指标 |
| 显示 | 外观：跟随系统/浅色/深色 | 即时生效；默认跟随系统 |
| 显示 | 登录时启动 | 默认关闭，展示实际注册状态和失败原因 |
| 记录 | 标准/省电采样 | 用“更新更及时/减少后台读取”说明取舍 |
| 记录 | 保存历史、保留周期 | 关闭后说明当前只显示实时数据；旧记录仍可手动清除 |
| 记录 | 导出、清除历史 | 清除前确认具体范围；导出结束说明实际保存路径 |
| 提醒 | 低电量、充至指定电量、插电持续放电 | 开启第一项时申请通知权限；拒绝后给系统入口 |
| 关于 | 版本、数据说明、开源致谢、退出 | 不展示设备唯一标识 |

第一版无需高级传感器开关、root 帮助程序或校准向导。采样开关写用户可理解的作用，字段和算法留在诊断说明。

## 8. 异常、加载和空状态

| 场景 | 文案 | 可用操作 |
|---|---|---|
| 第一次读取 | 正在读取电源信息… | 首次使用小型骨架，无虚构数值 |
| 刚插拔 | 正在更新供电状态… | 保留电量；旧功率变为占位 |
| 单项不支持 | — / 此项数据未提供 | 查看指标说明；其他项仍工作 |
| 读取暂时失败 | 数据暂未更新 · 上次更新于 19:42 | 自动退避重试；手动“重新读取” |
| 睡眠唤醒 | 正在恢复监测… | 首个有效样本后恢复；历史标记睡眠缺口 |
| 健康无历史 | 尚无足够记录 | 说明开始日期 |
| 已关闭历史 | 历史记录已关闭 | “开启记录”进入对应设置项 |
| 导出失败 | 未能保存文件 | 保留区间，重新选择位置 |
| 非支持设备 | 当前版本面向配备内置电池的 MacBook | 查看支持范围、退出 |

时效规则：面板展开时超过 5 秒没有有效读数、收起时超过配置采样周期的 3 倍，进入过期状态。过期数字可在详情中保留，并显式标注时间；菜单栏不继续当作实时功率显示。休眠期间的停采不是错误通知。

## 9. 通知交互

提醒是用户可选功能。低电量阈值默认建议 20%，用户可改；这是提醒阈值，不是电池健康诊断阈值。充电到达通知默认建议 80%，文案只说到达指定电量，不声称应用停止充电。

通知点击后打开相关实时状态；通知中带事件发生时间，避免历史通知误导为当前状态。切换源或关闭某提醒后清除其尚未发出的待发送事件。

## 10. 无障碍与本地化

- VoiceOver 读作“电池正在充电，27.6 瓦”，不只读加号；读作“电池正在放电，12.4 瓦”，不让用户猜负号。
- 数值更新不每秒触发朗读。状态切换才发低优先级提示，用户聚焦时可主动读取最新值。
- 颜色之外还有标签、方向、正负号和线型。深色模式不是简单反相；透明度关闭后用实色维持对比度。
- 图表有文本摘要和键盘取样；只展示图形不能算趋势可访问。
- 中文优先，字符串抽离以支持英文；长文案允许换行，不缩小功率数字。小数、日期和时区使用系统区域设置。
- 减少动态效果时取消能量流动画；不能靠动画方向作为唯一信息。

## 11. 视觉稿评审与实现约束

三张图统一使用 65% 电量、65 W 系统报告供电能力、61.6 W 输入、+27.6 W 充电、34.0 W 整机功率、100% 健康、144 次循环，便于比较信息层级。历史曲线与时间估计是示例。

已检查：数值分层、功率命名、充电方向、示例标识和主要中文内容可读。没有进行真实用户测试或原生窗口尺寸测试。

进入实现时须收紧的细节：

1. 菜单栏图标统一为原生单色模板；概念图的着色电池不作为强制实现目标。
2. 按最终选定的面板尺寸重新排版，不把整张生成图片作为应用界面。
3. 百分比分配条只在来源与口径已验证的状态显示；不满足条件时保留独立读数，不显示精确分配比例。
4. “电池健康”摘要中的 100% 在详情展开为“最大容量 · 系统报告”。
5. 选定方向后补齐浅深色、放电、暂停、数据缺失、趋势、健康和设置的高保真状态，再做可点击原型。

方案 1 已获用户选择，现已完成网页交互原型，覆盖实时、趋势、健康、设置、指标说明，以及充电、放电、暂停、满电、插电仍在放电、缺失和过期数据。页面均支持浅色、深色、跟随系统，行为见 [外观规格](appearance.md)。原型使用示例数据；原生程序、真实设备读数与系统无障碍适配仍需独立验收。
